# ERP Domain Audit — 2026-07-05

## Executive Summary
Across all 10 ERP domains (161 modules total), zero domains reach "world-class" or even "good with minor gaps" — every domain is rated "significant" world-class gap, and four domains (Procurement, GRC, Analytics, Platform) have views that never left basic-crud or stub quality. The highest-priority failures are not missing features but outright runtime crashes: GRC's ERM dashboard raises ImportError on startup due to wrong model class names, SoD KPI counters silently return 0 by querying the wrong model, and the Projects module has no views.py at all despite 12 view classes being imported at startup. The clearest path to measurable improvement is a two-track approach — fix the crashes and semantic bugs first (hours, not days), then close the most visible UI gaps that define parity with SAP S/4HANA, Workday, and Salesforce (Gantt wiring, 9-box calibration, Kanban pipeline, period-close workflow).
