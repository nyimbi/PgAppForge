## 🚀 Getting Started

### Prerequisites
- Python 3.9+ (3.11 recommended)
- Redis (for real-time features)
- PostgreSQL (recommended for production)

### Quick Installation

```bash
# Clone the enhanced Flask-AppBuilder
git clone https://github.com/dpgaspar/Flask-AppBuilder.git
cd Flask-AppBuilder

# Install with all features
pip install -e ".[mfa,export,analytics,oauth,openid,talisman]"

# Start Redis for real-time features
redis-server

# Follow the getting started tutorial
cd examples/quickhowto
python app.py
```

### Environment Setup

```bash
# Required for AI features
export OPENAI_API_KEY="your-openai-key"
export ANTHROPIC_API_KEY="your-anthropic-key"

# Optional for additional providers
export GROQ_API_KEY="your-groq-key"
export GOOGLE_API_KEY="your-google-key"
```
