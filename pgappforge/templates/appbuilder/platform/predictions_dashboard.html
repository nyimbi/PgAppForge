{# ── Embedding guide ──────────────────────────────────────────────────── #}

Embed in List Views

Add inline prediction badges to any ERP list view using the /api/predict endpoint or the bulk pre-load endpoint.

Single record badge (GET) 

GET /platform/predictions/api/predict
    ?type=credit_score
    &id=<application_id>

→ {
    "score_pct": 72,
    "label":     "HIGH",
    "color":     "#e02424",
    "tooltip":   "Short tenure; Low rating",
    "from_cache": false
  }

List-view bulk pre-load (POST) 

POST /platform/predictions/api/bulk
Content-Type: application/json

{
  "type": "duplicate_invoice",
  "ids": ["inv-1","inv-2","inv-3"]
}

→ {
    "results": {
      "inv-1": {"score_pct":92,"label":"DUPLICATE",...},
      "inv-2": {"score_pct":8, "label":"UNIQUE",...}
    }
  }

Results are cached in plat_ml_prediction for 24 hours. Bulk requests are capped at 20 fresh computations per call to bound latency.
